# CLI

This section covers using Replycant CLI tools on Linux and macOS.

Download `git-replycant` and `replycant-importer` binaries from the
project GitHub Releases page, then place them on your `PATH`. The
`git-replycant` archive also contains a `git-remote-replycant` symlink;
git will not reach a repository without it.
