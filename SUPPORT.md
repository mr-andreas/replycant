# Replycant Support

Replycant is open source and community-supported.

## Get help

- Issue tracker: https://github.com/mr-andreas/replycant/issues
- Documentation: https://github.com/mr-andreas/replycant/tree/main/docs
- Releases and server bundle: https://github.com/mr-andreas/replycant/releases

## Include this information when reporting problems

- iOS version
- Replycant app version
- Server version
- Steps to reproduce
- Relevant logs or screenshots
